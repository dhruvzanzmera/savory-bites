# Savory Bites

A modern, responsive restaurant landing page built with HTML, CSS, and Bootstrap.

## Overview

This project showcases a fine dining restaurant homepage with the following sections:

- Hero banner
- Menu tabs and dish listings
- Image gallery
- Testimonials
- Reservation form
- Footer

## Files

- `index..html` — main website file containing structure, styling, and interaction logic.

## Features

- Single-page responsive layout
- Single font family applied across the site
- Interactive menu filter
- Responsive gallery and testimonials section
- Reservation form with client-side acknowledgment

## Usage

1. Open `index..html` in a web browser.
2. Use the navigation links to jump between sections.
3. Click menu tabs to filter dishes.
4. Fill the reservation form and submit to show a confirmation note.

## Notes

- The site uses Bootstrap v5 and Bootstrap Icons.
- Animations and scroll effects have been removed for a static presentation.
